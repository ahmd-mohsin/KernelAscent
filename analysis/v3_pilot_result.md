# v3 causal pilot: self-improvement is real, recursion is not (n=4 lineages, pilot)

Two-link lineage instrument (actor/target separated, common target at each link, rescue) on
real models. Bounded C(S) in {0,0.5,1.0} on private-seed Medium kernel projects. 4 independent
lineages per agent. Calibration suite (ALL PASS) established the instrument distinguishes
recursive from one-upgrade from best-of-N before this run.

Read: one-shot self-improvement is supported (q1-q0 CIs exclude 0 for both). Recursive
improvement is NOT: the causal producer contrast F1 ~ 0 (CIs span 0) and F2 <= 0. This is the
one-upgrade signature (dQ>0, F2~0), not the recursive-positive signature (F1>0, F2>0) the
calibration can detect. So on this pilot the agents improve once but do not causally compound
their improvement procedure.

Caveats: n=4, wide CIs; bounded C(S) with a compile-baseline attainment target; revise edits
target params (not full source rewrites). A confirmatory run needs more lineages for precision.
