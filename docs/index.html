GPU kernel benchmark

KernelAscent

Models write GPU kernels. Each kernel is graded for correctness against a reference and for speed against a baseline. The benchmark asks two things: how well a model does in one shot, and whether it gets better when it trains on, or edits, its own work over several rounds.

Tasks

TaskWhat it measuresModels
1. CapabilityCan the model write a correct, fast kernel in one shot?open and closed
2. Weight self-improvementThe model trains on its own correct kernels each round. Does it get better than a matched control?open weights
3. Procedure self-improvementWeights stay fixed; the model rewrites its own strategy and solver prompt each round.open and closed
4. Closed → openA closed model rewrites the training setup of an open model.closed + open
5. Self-playThe model writes harder tasks for itself, then solves them.open and closed
