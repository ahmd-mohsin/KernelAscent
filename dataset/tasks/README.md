# KernelAscent Tasks (public split)

Difficulty-graded Python bug-fix tasks used by the **KernelAscent** benchmark — a benchmark of agents
that improve with experience. Each task was generated by a single strong curator (Fable 5.1 at high
reasoning effort) and **admitted only after executable validation**: the reference implementation must
match every example and never raise on sampled or edge inputs; the buggy variant must be genuinely
wrong yet plausible; and for `medium`/`hard`/`ultra`, the buggy variant must *agree with the reference
on typical inputs but differ on edge cases* (a plausible fix that misses an edge). Duplicates (by slug
and by reference-code hash) are removed.

## Splits (difficulty tiers)

| tier   | what makes it hard |
|--------|--------------------|
| easy   | basic list/string/number transformation; few edge cases |
| medium | correctness hinges on 1–2 edge cases a plausible fix misses |
| hard   | multiple interacting rules / a subtle specification |
| ultra  | competition-hard algorithm (parsing / DP / number theory / geometry) with many edge cases |

## Fields

- `name` — short slug
- `fn` — function name to implement/fix
- `spec` — 1–2 sentence exact behavior + input domain
- `reference_code` — a correct `def fn(...)`
- `buggy_code` — a plausible but wrong `def fn(...)` (same signature) — the starting point to fix
- `sampler_code` — `def sample(rng)` returning valid in-domain args
- `edge_code` — `def edge(rng)` returning edge-case valid args
- `examples` — list of `[args_list, expected_output]`
- `tier`, `split`, `id`

## Held-out test set

This dataset is the **public / development** split only. A separate held-out test split (~35% of each
tier) is **never published** and is used to score the KernelAscent leaderboard, so leaderboard numbers
cannot be contaminated by training on this data. Do not attempt to reconstruct it.

## Usage

```python
from datasets import load_dataset
ds = load_dataset("muahmed7338/kernelascent-tasks")
task = ds["medium"][0]
# fix task["buggy_code"] so it matches task["reference_code"] on sampled + edge inputs
```
